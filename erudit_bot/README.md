# Erudit-bot (прототип)

Алгоритм: **сенсаційна новина на Tribuna → клікбейтний тизер → пост у Telegram-каналі**.

1. Бот забирає свіжі новини зі стрічки **tribuna.com**.
2. AI оцінює «гучність» кожної (1–10) і пропускає рутину (нижче `ERUDIT_MIN_SCORE`).
3. Для сенсацій пише тизер, який не розкриває головного:

```
[фото з новини]

🧡 «Всі футболісти заслуговують на величезні оплески»   ← жирним

Рінат Ахметов прокоментував перемогу «Шахтаря» у Лізі чемпіонів 💬

Кого саме виділив 👇
[ ЧИТАТИ ↗ ]   ← кнопка веде на повну новину на Tribuna
```

4. Запам'ятовує оброблені новини в SQLite, щоб не дублювати.

## Налаштування

1. Створіть бота в [@BotFather](https://t.me/BotFather) і додайте його **адміністратором** каналу з правом публікації.
2. Додайте в `.env`:

```env
OPENAI_API_KEY=sk-...
ERUDIT_TELEGRAM_BOT_TOKEN=123456:ABC...
ERUDIT_CHANNEL_ID=@my_channel          # або -100xxxxxxxxxx

# необов'язково
ERUDIT_SOURCE_URLS=https://tribuna.com/uk/news/,https://tribuna.com/uk/football/news/
ERUDIT_OPENAI_MODEL=gpt-5.6-luna
ERUDIT_MAX_POSTS_PER_RUN=3     # максимум постів за прохід
ERUDIT_MAX_CANDIDATES=10       # скільки свіжих новин оцінює AI за прохід
ERUDIT_MIN_SCORE=6             # поріг «сенсаційності» 1-10
ERUDIT_INTERVAL_MINUTES=30
ERUDIT_POST_DELAY_SECONDS=5
ERUDIT_DB_PATH=erudit_bot.db
```

Залежності ті самі, що й у BizBot: `pip install -r requirements.txt`.

## Запуск

```bash
# перевірити, що бот бачить канал і може в нього писати
python -m erudit_bot --check

# подивитися, які пости вийдуть, нічого не надсилаючи
python -m erudit_bot --dry-run

# переписати й опублікувати конкретну статтю (без фільтра гучності)
python -m erudit_bot --url https://tribuna.com/uk/news/...

# один прохід (для cron / Railway cron)
python -m erudit_bot --once

# постійна робота: перевірка кожні ERUDIT_INTERVAL_MINUTES хвилин
python -m erudit_bot
```

## Як влаштовано

| Файл | Що робить |
|---|---|
| `scraper.py` | Посилання на новини зі стрічки + розбір статті: JSON-LD `NewsArticle` → og-теги → абзаци в `<article>` |
| `writer.py` | Промпт редактора: заголовок-цитата, тизер, гачок 👇 і оцінка гучності; збирає пост у Telegram-HTML у межах лімітів |
| `publisher.py` | `sendPhoto` з кнопкою «ЧИТАТИ ↗»; якщо фото не вантажиться — текстом з тією ж кнопкою; `--check` прав бота |
| `storage.py` | SQLite-таблиця вже опублікованих URL |
| `main.py` | Пайплайн і CLI |

Поведінка при помилках: якщо впав AI чи Telegram — новина не позначається опублікованою і буде спробувана наступного проходу; порожня або «нудна» стаття пропускається назавжди. Нові пости йдуть від старішого до новішого, щоб у каналі зберігся хронологічний порядок.

## Деплой на Railway

Окремий сервіс з цього ж репозиторію, start command: `python -m erudit_bot`. Підключіть volume (наприклад, `/data`) і задайте `ERUDIT_DB_PATH=/data/erudit_bot.db`, інакше після кожного редеплою бот забуде опубліковане й почне дублювати пости.

## Обмеження прототипу

- Розмітку tribuna.com не перевірено наживо (з середовища розробки сайт недоступний). Якщо посилання не знаходяться — перевірте `is_article_url` у `scraper.py` і запустіть `--dry-run`.
- Стиль постів і критерії «сенсаційності» налаштовуються в `SYSTEM_PROMPT` у `writer.py`.
- Тексти — переказ із посиланням на джерело; перед комерційним використанням варто перевірити умови використання контенту Tribuna.
